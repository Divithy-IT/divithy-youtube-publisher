# Współpraca

1. Utwórz gałąź od `main`.
2. Nie dodawaj tokenów, sekretów OAuth ani plików wideo.
3. Uruchom `python -m unittest discover -s tests -v`.
4. Opisz zmianę i sposób jej sprawdzenia w pull requeście.

Zmiany harmonogramu powinny zawierać test uwzględniający strefę
`Europe/Warsaw` oraz kolejność publikacji.
