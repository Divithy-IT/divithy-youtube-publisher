# Bezpieczeństwo

Nie publikuj w zgłoszeniach plików `client_secret*.json`, `token*.json`,
`publisher_config.json`, historii wysyłania ani prywatnych materiałów wideo.

Podatności zgłaszaj prywatnie przez funkcję **Report a vulnerability** w
zakładce Security repozytorium. W zgłoszeniu podaj wersję, system i możliwie
krótki sposób odtworzenia problemu, bez prawdziwych danych logowania.
